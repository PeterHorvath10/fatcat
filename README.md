# FATCAT

Code and artifacts for the paper [FATCAT: Fault Injection Attacks Targeting Chip-level Alignment](https://arxiv.org/abs/2611.31129) (arXiv:2611.31129).

The repository has three parts, each with its own README: [`jailbreak_emfi/`](jailbreak_emfi/) for the EM fault injection experiments on language models, [`robot_emfi/`](robot_emfi/) for the robot arm experiments, and [`format_sim/`](format_sim/) for the software simulation of faults across weight formats.
